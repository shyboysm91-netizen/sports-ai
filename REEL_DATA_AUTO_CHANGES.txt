릴스 실제 경기 분석 데이터 자동 연결

수정 범위
- app/lib/content-analysis.ts 신규 추가
- app/content/ContentClient.tsx의 경기 선택 시 릴스용 분석값 자동 입력
- app/lib/auto-content.ts의 서버 자동 릴스에 실제 분석값 반영

반영 데이터
- 선발투수 및 ERA
- 최근 10경기 승패
- 최근 맞대결
- AI 승리 확률
- 예상 스코어
- 핵심 분석 문장

보존 범위
- KBO/MLB/NPB 기존 경기 분석 페이지 및 기존 계산 코드는 수정하지 않음
- 자동 콘텐츠/릴스 관련 파일만 수정 또는 추가
