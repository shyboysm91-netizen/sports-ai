변경 내용
1. 메인 페이지를 서버 컴포넌트로 전환
2. 오늘 KBO 경기 데이터를 서버에서 먼저 불러와 초기 HTML에 포함
3. 기존 KBO/MLB/NPB 탭, 날짜 선택, 경기 카드와 상세 링크 유지
4. 선발투수 비교 기준, 불펜 피로도, AI 예측 기준 설명 추가
5. 경기 분석 이용 안내와 내부 링크 추가
6. 메인 페이지 고유 메타 제목과 설명 추가
